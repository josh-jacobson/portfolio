Portfolio
========

My main website, built with:
* React
* Next.js
* Chakra UI

and hosted on Vercel at joshjacobsonmusic.com. Shouts out to Lee Robinson for inspiring the initial design and application structure.

Upgraded in 2025 to use Node v22.14.0 after Vercel deprecated Node 18
Upgraded Next version to 15.3.6 in 2026 to fix a vulnerability in 15.3.0

Local server on port 3000:
npx next dev

Troubleshooting:
nvm use v22.14.0
yarn install

Deployment: Vercel (pushing to staging or main branch automatically triggers a build for staging or production)
